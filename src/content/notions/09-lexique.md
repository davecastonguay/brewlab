## L'essentiel

| Mot | Définition |
|---|---|
| **Adjuvant** | Céréale non maltée (souvent en flocons) ajoutée pour la texture ou la mousse |
| **Acides alpha (AA)** | Le % du houblon qui donne l'amertume |
| **Atténuation** | Le % du sucre mangé par la levure |
| **Bazooka** | Filtre en tube au fond de la cuve, seulement pour le houblon en fleurs |
| **Bioxy** | Désinfectant à base d'oxygène, sans rinçage |
| **Bonde / soupape / barboteur** | Laisse sortir le CO₂ du fermenteur sans laisser entrer l'air |
| **Densité (DI / DF)** | Quantité de sucre dans le liquide : initiale (avant) et finale (après la fermentation) |
| **Dry hopping** | Ajouter du houblon dans le fermenteur, pour l'arôme seulement |
| **Empâtage** | Tremper le grain concassé dans l'eau chaude pour transformer l'amidon en sucre |
| **IBU** | Unité d'amertume |
| **Krausen** | La mousse qui se forme sur la bière en pleine fermentation |
| **Lovibond (°L)** | Mesure de la couleur d'un malt |
| **Mash-out** | Monter à ~75 °C à la fin de l'empâtage pour arrêter les enzymes |
| **Moût** | Le liquide sucré avant la fermentation |
| **Palier** | Une température tenue pendant un temps donné pendant l'empâtage |
| **PBW** | Nettoyant puissant (Powdered Brewery Wash), à l'eau chaude |
| **Saccharification** | La transformation de l'amidon en sucres fermentables |
| **Sparge** | Rincer le grain à l'eau chaude pour récupérer le sucre restant |
| **Tourie** | Bonbonne en verre pour la fermentation secondaire |
| **Whirlfloc** | Comprimé clarifiant ajouté 15 min avant la fin de l'ébullition |
| **Whirlpool hopping** | Ajouter du houblon après l'ébullition, vers 70-80 °C, pour l'arôme |

## Pour aller plus loin

La devise du cours : **« Small batch, more batch »**. Faire des petits brassins souvent, c'est la meilleure façon d'apprendre.
